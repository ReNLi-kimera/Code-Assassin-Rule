# Code:Assassin β
MinecraftVersion 26.2  
標的やターゲットを暗殺し最後まで生き残れ  

## 基本ルール  
* 準備時間のフェーズ0、戦闘時間のフェーズ1、フェーズ2  
* 最大人数12人  
* プレイヤーには「役職」「Code(ナンバー)」「Color(カラー)」が与えられる
  * 「Code」は完全秘匿情報、「Color」はTABで初期のみ確認可能  
* チェストには「水晶」「アイテム」「レアアイテム」が入っている
* 「素手攻撃」は何も持ってない状態じゃないとダメージが通らない  
* クリティカルダメージは存在しない  

## 詳細ルール  
* 「役職」はフェーズ0とフェーズ2開始時は表示されない
 * フェーズ2開始時に役職が再配布される
 * フェーズ2はチェスト内に入っている「IDカード」を所持することで役職が分かる
* フェーズ2は生存人数が5人以上の場合のみ開始する
* フェーズ1終了時に生存人数が4人以下だった場合はその時点でゲームが終了する
* 「Code」は1~12で他人からはわからない  
* 「Color」はTABで確認できるがアイテム、「カラーアイ」使用後の色はわからない  
  * フェーズ2開始時に「Color」が更新される  
  * 「Color」は「アクア」「ブルー」「ダークアクア」「ダークブルー」「ダークグリーン」「パープル」「ダークレッド」「ゴールド」「グリーン」「ピンク」「レッド」「イエロー」  
* エリア一か所にアイテムショップがある  
  * 「VIPカード」をもってアイテムショップに話しかけると「VIPアイテムショップ」を見ることができる  
* 「VIPアイテムショップ」のアイテムは1個買うと売り切れになる
* 「VIPアイテム」はフェーズ終了時に没収されVIPアイテムショップに再補充される  
## 役職と誤殺ペナルティ  
* 役職にはそれぞれに誤殺ペナルティが決められている
* 誤殺対象を暗殺しようとすると相手は死亡せず自分が死亡する  
### アサシン  
* 自分のターゲット以外  
### ターゲット  
* 自分がターゲットのアサシン以外
### イノセント  
* アサシン以外
